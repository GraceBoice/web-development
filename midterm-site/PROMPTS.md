
# AI Prompts Used for My Midterm Website

I used ChatGPT to help create the starting version of my website for my web development class.

## Prompt 1 - Website Design

Create a simple personal website using HTML and CSS. I want it to look like a college student's personal website, with a cute pink scrapbook theme. Keep the design casual and personal.

The website should have five pages:
- Home
- About Me
- Little Projects
- Photo Dump
- Contact

Use a shared navigation menu and an external CSS file. Keep all the files in one folder.

## Prompt 2 - Personalization

Make the website feel more personal and less like a professional business website. Use casual writing, soft pink colors, and simple styling.

## Prompt 3 - Photos

Help me include four of my own photos in the website. Make sure the images have descriptive alt text and work with the HTML pages.

## Prompt 4 - GitHub

Walk me through creating the website files in my existing GitHub repository using the browser-based VS Code editor.
